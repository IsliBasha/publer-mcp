# Product

## Register

product

## Users

Social media managers who want AI-assisted scheduling, caption generation, and analytics through Claude Desktop — no complex setup beyond initial install. They manage a creator's or brand's full social presence across LinkedIn, Instagram, Twitter, TikTok, Facebook, Pinterest, and YouTube.

Secondary audience: hackathon judges and developers evaluating the integration as a model for AI-native tooling on top of Publer's platform.

## Product Purpose

An AI-native social media operating system that bridges Claude Desktop to Publer's platform via Model Context Protocol. Users manage their entire social workflow — scheduling, analytics, content generation — through natural language conversations with Claude. A real-time dashboard makes the AI's actions visible and the system's state legible at a glance.

Success: a judge watches the demo and says "this feels like a real Publer product." A social media manager can replace their manual Publer session with a Claude conversation.

## Brand Personality

Bold, expressive, social. The product reflects Publer's platform energy — it's the control room for a creator's public voice, not a quiet infrastructure tool. Tone is confident and capable with enough warmth to feel human. Three words: commanding, alive, social.

## Anti-references

- Generic SaaS dashboard templates: sidebar + gray metric cards + blue chart + white background
- shadcn/ui defaults used without customization — the "I installed a library" look
- Toy prototype energy: fragile, unstyled, "just works" without visual confidence
- Dark mode with purple gradients or neon accents
- The hero-metric template: big number, gradient accent stripe, supporting stats in a row
- Glassmorphism used decoratively
- Identical card grids with icon + heading + text repeated endlessly

## Design Principles

1. **Real-time first.** The dashboard is a live view of system state. Every meaningful action — post scheduled, caption generated, queue retry — is immediately reflected. Static screenshots should look incomplete.

2. **Demo-impressive at a glance.** A judge who sees this for 3 seconds should feel "this team built something real." Visual confidence justifies technical confidence.

3. **AI-native, not AI-adjacent.** The UI makes Claude's role legible: tool calls are surfaced, AI-generated content is attributed, the AI console is a first-class screen — not a sidebar afterthought.

4. **Social energy.** Publer is a creative platform. The dashboard should reflect that energy — not corporate gray, not startup-minimal — but bold and contextually alive.

5. **Production-realistic.** Every component looks funded and shipped. Hover states, loading states, empty states — all designed, never accidentally missing.

## Accessibility & Inclusion

WCAG AA minimum. Keyboard navigable throughout. Color contrast 4.5:1 minimum for body text, 3:1 for large text and UI components. Reduced-motion support for all real-time transitions and animations.
